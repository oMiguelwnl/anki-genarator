<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| benchmark fixture file → evaluation loader | Untrusted or malformed benchmark JSON crosses into the harness |
| quality-report-like metric payload → aggregator | Report-shaped data from runtime artifacts may be incomplete or tampered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | T | `ankideck_generator/core/evaluation.py` fixture loader | mitigate | Validate every benchmark row with Pydantic before use; reject missing slice labels, invalid enums, and wrong metric shapes with explicit exceptions. |
| T-05-02 | R | experiment fingerprint fields in evaluation output | mitigate | Derive a stable fingerprint from canonical JSON ordering of benchmark inputs and experiment metadata so reports can prove what was evaluated. |
| T-05-03 | D | aggregation entrypoints | mitigate | Keep aggregation pure and input-bounded to repo fixtures and explicit report payloads; never trigger provider calls or live retries from evaluation helpers. |
</threat_model>
