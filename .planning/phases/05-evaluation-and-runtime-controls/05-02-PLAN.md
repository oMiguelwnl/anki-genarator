| export cleanup → retained evaluation evidence | Cleanup logic can destroy required benchmark evidence if misconfigured |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-05 | D | `DeckBuilder._process_word_textual()` AI stages | mitigate | Reuse the existing global budget gate and add stage-specific counters plus explicit denial events so runaway retries stop before exhausting a run. |
