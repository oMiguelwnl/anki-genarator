<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated card text → duplicate validator | Untrusted candidate text is compared against trusted accepted-card memory |
| validator result → DeckBuilder rejection path | Duplicate evidence crosses from validation into orchestration and later audit artifacts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | T | duplicate normalization | mitigate | Normalize with NFKC + lowercase + punctuation stripping so trivial formatting changes cannot tamper with exact-match detection. |
| T-04-02 | D | near-duplicate comparison loop | mitigate | Limit fuzzy comparison to a same-focus shortlist of at most 12 accepted candidates before running `SequenceMatcher`. |
| T-04-03 | R | duplicate rejection evidence | mitigate | Capture structured `DuplicateDecisionEvidence` on the validation path so later queue/report artifacts can explain why a candidate was rejected. |
</threat_model>
